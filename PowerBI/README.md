# Power BI Dashboard

This folder contains the Power BI report and dashboard screenshots for the Delhi Road Accident Analysis project (2019–2023).

## Power BI Report

**File:** `Delhi_Accident_File.pbix`

The interactive Power BI report contains two pages:

### 1. Monthly Accident Analysis
- Presents monthly road accident patterns from 2019 to 2023.
- Allows users to explore accident trends across different years.
- Includes key performance indicators (KPIs), charts, and year-based slicers.

### 2. Time-Slot Analysis
- Examines the distribution of road accidents across different time slots.
- Compares accident counts across the five-year period.
- Includes KPIs, a matrix, and year-based filtering.

## Dashboard Screenshots

The `Dashboard_Screenshots` folder contains screenshots of the report pages, including views with slicers applied.

These screenshots provide a preview of the Power BI dashboard without requiring the report file to be opened.
