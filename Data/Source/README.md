# Source Data

The original data used in this project was obtained from the National Crime Records Bureau (NCRB), Chapter 1A – Traffic Accidents reports for the years 2019 to 2023.

The relevant accident data was manually extracted from the official NCRB reports, organised in Excel, cross-checked, and converted into CSV files for further analysis.

The original source reports are not included in this repository. They can be accessed through the official NCRB website.
